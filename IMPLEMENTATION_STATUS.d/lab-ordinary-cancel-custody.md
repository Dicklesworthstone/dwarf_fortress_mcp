# Cancellation checks for ordinary laboratory work

The ordinary cancellation path validates the work's kind, generation and original parameters before using its status. Construction checks its recorded required tokens and distinguishes exact-item placements. An older building without a token list can still match a build without required materials. An undispatched missing record and a repeat cancellation of the same valid record remain inert.

Three regression tests cover substitution, idempotence, material evidence and an exact bed refund. All five affected Rust files have been syntax-parsed. Rust test execution and qualification remain outstanding.
