# MCP named-civilian protection and current proof (2026-10-11)

The laboratory accepts a closed civilian_protection_v1 request through the
existing fortress.plan action input. The new civilian_protection query recomputes
current three-valued configuration truth and assigned/unassigned/unknown counts
from one reference snapshot, independent of historical completion receipts.
It does not infer physical evacuation, safe terrain, population completeness,
threat clearance or native support. Protective cancellation never supplies
release authority. The ordinary ConfigureLogistics/Guarded and Checkpoint gates
remain, and current Query authority owns the read path.

Eight new facade/decoder test functions plus the preceding eleven core/adapter
cases are source-present and reviewed, not Rust-compiled or executed. Two Draft
2020-12 schemas and both examples pass Python validation; all 84 malformed
structural mutations reject. This is only structural schema evidence. Native
protocols, compatibility admission and production runner maps are unchanged.
