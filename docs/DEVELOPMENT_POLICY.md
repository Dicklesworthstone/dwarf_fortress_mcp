# Development policy

`dwarf_fortress_mcp` is source-available for inspection and use, but development is intentionally closed.

The maintainer does not accept pull requests, unsolicited patches, contribution proposals, contributor onboarding, or requests for commit access. Public issues may be used to report reproducible defects or document concrete behavior, but they do not create an expectation that outside implementation work will be reviewed or merged.

All authoritative development is performed directly by the maintainer and explicitly authorized agents. This keeps architectural custody, security boundaries, release evidence, dependency policy, and semantic compatibility under one accountable control plane.

Forks remain permitted under the repository license. A fork is independent: it must use its own name, release process, compatibility claims, and support channels, and it must not imply that its changes are endorsed or supported by this repository.
