# Keep original terrain history through durable placement

Furniture batch/4 imports the full terrain handoff, retains its raw map and
original journal identity, and holds replayed terrain custody before new native
work. Missing terrain blocks new placement but never original-key recovery.
Seventeen Python/POSIX/TCP/CLI methods pass, including 32 exact placements with
646 exclusions. Thirty prior batch/1-/3 outputs match byte-for-byte. Native
protocols, child journal framing, old keys and production admission are unchanged.
