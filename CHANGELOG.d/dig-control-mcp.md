Register the separate dfmcp-dig-control-dev-server on the existing eleven-tool
waist. Compose owned native sessions, durable Rust journals, actual host spatial
lease verification, protected shared blocks and policy-bound confirmation seals.
Observe, prepare and commit retain the same source; commit has no connection
factory or retry. Query-only recovery and exact native preparation retirement
preserve uncertainty and retained history. Existing recovery-only MCP is unchanged.

Default checkpoint policy refuses new designation. Only explicit trusted operator
selection of a disposable fortress permits the development no-checkpoint exception;
no game checkpoint, safety, excavation completion or production admission is claimed.
Reserve complete Agent Turns and final custody reads, keep pending work visible,
and use inherited runtime-owned blocking tasks with joined results.

Seventeen handler and five runtime/configuration Rust tests are registered but
uncompiled/unexecuted. The executed JSON Schema suite passes 28 valid and 102 invalid
cases; it does not execute Rust, MCP, native I/O or storage. See docs/DIG_CONTROL_MCP.md.
