### Fixed native mining/1.15 RPC bridge

Connect bounded ordinary-mining preparation, commit and query to a separate
five-method native plugin. Capture complete small visible halos, redact hidden
cells before attribute reads, preflight every target pointer before writes,
preserve priorities and unrelated fields, and recheck operator designation
permission per prepare/commit. Recover stored receipts after lost replies without
repeating setters; lifecycle changes invalidate preparations and missing keys
remain uncertain. No clock, terrain-excavation, arbitrary-command or MCP edge.

GCC and Clang each pass 9,201 actual-handler assertions with explicit SDK/protobuf
API doubles, warning denial and UBSan, and reject four compiled mutants. Real
SDK/protobuf ABI, live-fortress, Rust/MCP and production admission remain unproved.
The engine tests separately pass 4,774 assertions and four independent vectors.
Contract and operator details: docs/BOUNDED_MINING.md.
